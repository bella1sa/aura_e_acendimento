O Aura & Acendimento  é um site simples e direto para exibição e venda de velas aromáticas.
O objetivo do site é ser uma vitrine limpa, funcional e sem complicações, onde o cliente acessa, escolhe a vela e faz o pedido rapidamente.

## O que o site é:
Uma loja virtual de página única focada em apresentar a marca e os produtos de forma visual, elegante e objetiva.

## Funções do Site:
Banner Principal: Apresentação da marca com destaque visual para as velas.
Vitrine de Produtos: Exibição dos modelos de velas em formato de grade (cards) contendo:

Foto do produto

Nome da vela

Descrição do aroma (ex: Lavanda, Baunilha, Alecrim)

Preço

Detalhes do Aroma: Texto curto em cada card explicando a sensação que a vela proporciona (ex: Relaxamento, Foco, Aconchego).

Botão de Compra / Pedido: Botão em cada produto que redireciona o cliente diretamente para o WhatsApp com uma mensagem pronta contendo o produto escolhido para finalizar a compra.

Seção "Sobre a Marca": Pequeno texto informativo destacando diferenciais (ex: Cera 100% vegetal, feita à mão).

Rodapé: Informações de contato, links para redes sociais e formas de pagamento aceitas.

FRONTEND: CSS + HTML
BACKEND: EXPRESS + NODE.JS
